# Assurance boundaries

The theorem combines a written semantic reduction with finite interval and
graph checks. Each layer is necessary; no metadata check replaces the argument.

| Dimension | Evidence and limit |
|---|---|
| Statement | Full closed specified Szöllősi family, including degeneracies; not the unrestricted dimension-six conjecture. |
| Mathematical bridge | Canonical half-open parameter ownership, closed interval enclosures, complete vector hull coverage, separation, and forbidden pair of six-cliques. |
| Arithmetic | IEEE binary64 with strict compilation and outward rounding; interval table verification; runtime/compiler/hardware remain trusted. |
| Generator | Untrusted proposal mechanism. Numerical root counts and radius heuristics are not proof. |
| Replay | Fresh clean replay passed 14,658 Szöllősi and 1,935 Fourier boxes, including 75 freshly subdivided boundary parents. Full bound records are in replay/. Historical receipts were not imported. |
| Negative controls | Changed-hull legacy-cache attack, changed context/input tests, kernel override rejection, boundary owner and mixed-term fixtures. |
| Testing | Eleven kernel groups passed locally. Supplied mutation history detects 16/17 mutations, not all possible defects. |
| Independence | Checker separately implemented from generator. This is implementation diversity, not external human verification. |
| Review | Supplied second review recomputed every graph and selected phase-space cases; it explicitly did not replay every phase-space certificate. |
| Novelty | Bounded source comparison; no guarantee of exhaustive search or priority. Fourier exclusion is prior work. |
| Formal verification | No proof-assistant end-to-end verification. |

Content hashes detect changed inputs. They do not authenticate arbitrary cached
claims of success. A clean replay therefore imports no historical pass records.
The added optimized-Python test guards against removal of required computation
inside assertions; it is not an exhaustive audit of all possible runtimes.
